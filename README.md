## 实证结果

原稿报告的高企首次认定 PPML 系数为 −0.124。复现这项基准估计仍需找回最终清洗面板。本次使用城市统计数据，对七个试点按公告前特征匹配，并统一比较各城市首个完整实施年的变化。

| 指标与方法 | 估计结果 |
|---|---|
| 专利总授权，一对一匹配 | 0.223062 个对数点，条件翻转检验 p=0.03125 |
| 专利总授权，一对五匹配 | 0.204632 个对数点 |
| 发明授权，一对一匹配 | −0.072716 个对数点，p=0.390625 |
| 发明相对于其他类型授权的三重差分（DDD） | 0.032507，城市聚类标准误 0.075236，t 检验 p=0.666048 |
| 企业相对于高校和科研机构的发明申请 DDD | 5 个试点城市，估计为 0.179145，调整公告前趋势后为 −0.313874 |

总授权的名义 p 值来自七对城市的 128 种身份翻转，前提是每对城市内的试点身份可等概率互换，且各对的分配独立。对总授权和发明授权两项比较作 Bonferroni 校正后，总授权 p=0.0625。这项探索性结果反映的是试点初期城市专利授权总量的相对变化。

## 数据和程序

| 文件 | 来源与覆盖范围 |
|---|---|
| `eps_city_panel.dta` | EPS 城市统计数据，2015—2024 年共 299 城、2,990 条城市年度记录 |
| `public_applicants.dta` | 国家知识产权局统计年报，2017—2025 年共 19 城、171 条记录，其中 5 城为试点。变量说明见 [字段表](applicant_dictionary.csv) |

城市专利匹配使用 2018—2024 年数据，候选对照池有 256 个城市。为统一济南的地域范围，程序先合并 2018 年济南和莱芜的可加总指标，再计算对数和比率，同时报告按原行政区划估计的结果。那曲 2020 年的发明授权数超过总授权数，因此从共同样本中剔除。

申请人报表在 2017—2019 年统计职务发明，从 2020 年起统计全部申请。申请人 DDD 取两个时期共有的企业、大学和科研机构三类，比较企业申请相对于大学和科研机构合计申请的变化。

在 Stata/MP 18 中将工作目录设为仓库根目录，运行以下命令。结果写入 `results/`。

```stata
do main.do
do cohort_models.do
```

`main.do` 估计七城匹配、专利类型 DDD 和城市专利总授权 PPML。`cohort_models.do` 估计申请人 DDD 和各批次融资指标的变化。旧版 Stata 输入与输出说明见[复现说明](REPRODUCE.md)。

两套软件核对了 12 组匹配结果、28 组申请人 DDD、8 组融资合并估计及专利类型 DDD。确定性估计的差异均小于 1e-10，配对翻转检验的 p 值一致。[逐项核对结果](cross_language_validation.json)
