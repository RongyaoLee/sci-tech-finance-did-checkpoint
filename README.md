# 科创金融改革试验区：Day 3 复现材料

研究问题：试验区是否促进高新技术企业发展，以及试点初期城市专利授权、企业创新和融资指标如何变化。

完整代码、数据和逐项来源放在 **source_bundle.zip**，下载后解压进入 `source_bundle`。仓库根目录另提供可直接运行的两份 Stata do 文件和两份数据。全部研究脚本均据现有文件归档；原始认定 PPML 的最终清洗面板尚未恢复，见下方限制。

## Stata 快速运行

已在 Stata/MP 18 上实际执行；核心程序只依赖 Stata 自带命令与 Mata，无需 SSC 安装。设置当前目录为仓库根目录，运行：

```stata
do main.do
do cohort_models.do
```

完整压缩包中对应命令为：

```stata
cd "你的路径/source_bundle"
do stata/main.do
do stata/cohort_models.do
```

结果写入 `results/`。`main.do` 实现七城一对五匹配、一对一全局最小距离且不重复匹配、七对全部 128 次条件身份翻转、专利类型 DDD 和城市授权总量 PPML 参照；`cohort_models.do` 实现申请人类型 DDD、政策前趋势调整和融资分批次变化。后一程序不重新计算 Python 的安慰剂排序分布。

## 数据

| 文件 | 内容 | 来源与处理 |
|---|---|---|
| eps_city_panel.dta | 299 城市、2015—2024 年、2,990 行；含城市编号及原始指标 | 用户提供 EPS 导出，CSV 和导出 ZIP 在完整包 work/；不得理解为 EPS 对再分发授权的证明 |
| public_applicants.dta | 19 城市、2017—2025 年、171 行；五个试点、14 个对照 | 国家知识产权局统计年报，CSV 含逐条来源网址，字段对应见 applicant_dictionary.csv |

EPS 的专利为件，GDP、贷款余额和财政科学支出按所供导出表的万元记录。`.dta` 保留数值，政策年份与区划处理在程序中生成。主样本取 2018—2024 年，按共同完整性标准七城专利匹配有 256 个未试点候选城市；2018 年济南与莱芜指标相加用于统一地域，同时保留原报口径。那曲 2020 年发明授权超过总授权，不能进入共同专利样本。

申请人数据 `v1/v2/v3/v6/v9` 分别为城市、年份、公告年、企业申请、大学与科研机构申请合计。DTA 的全部 23 个变量均附原字段标签，字典中保留完整列名。2017—2019 年表头为职务发明、2020 年起为全部申请，DDD 使用可连续比较的企业、大学、科研机构类别，避免将个人申请混入分母。

## 当前结果及解释范围

| 分析 | 结果 | 解释 |
|---|---|---|
| 七城总授权，一对一、首个完整实施年 | 0.223062，条件翻转 p=0.03125 | 探索性、名义水平；要求对内等概率可交换且各对独立 |
| 七城总授权，一对五 | 0.204632 | 同一组对照同时检查两项授权结果 |
| 七城发明授权，一对一 | −0.072716，p=0.390625 | 没有相应正向证据 |
| 专利类型 DDD | 0.032507，聚类 SE=0.075236，Stata t 参照 p=0.666048 | 发明相对于实用新型和外观设计；并非高技术行业 DDD |
| 企业相对大学/院所申请 DDD | 平均差分 0.179145；预趋势调整后 −0.313874 | 公开城市覆盖不足七城，且对趋势调整敏感 |
| 原稿首次认定 PPML | 原稿报告 −0.124 | 仅作原文基准参照，本包未重新运行此原始回归 |

总授权与发明授权两项 Bonferroni 调整后，总授权 p=0.0625。这尚未计入全部探索，不能将名义显著扩写为“高新技术企业发展显著改善”。行政选点不是随机分配；匹配、SDID、翻转或安慰剂排序均不能自动解决选择偏误。

Stata 和 Python 比较了 12 组匹配、28 组申请人 DDD、8 组融资合并估计及专利类型 DDD。确定性估计误差均小于 1e-10；全部配对翻转 p 值一致，详见 cross_language_validation.json。专利类型 DDD 的 Stata t 参照与 Python 默认正态参照不同，另列可比正态 p=0.665693。

## 完整包目录

- `work/`：Python 数据清洗、分批次匹配 DID、SDID、两类 DDD、融资口径核对、敏感性及探索记录，含输入与结果。
- `stata/`：两个 do 文件、两份 dta、城市和变量字典。
- `crawlers/enterprise/`：恢复的高企名单采集、PDF/Word 解析、城市识别和历史补齐脚本。
- `crawlers/patents/`：恢复的专利数据采集脚本。
- `crawlers/cnipa_grants.py`：国家知识产权局三类授权年报采集，3 个并发，逐页保存 URL 与哈希。
- `outputs/公开数据补充/`、`outputs/public_patents/`：公开来源面板、融资研发质押证据表和逐数来源。
- `logs/`：已恢复的 DeepSeek、Codex 任务记录及明确标记的回忆补记。
- `docs/`：清单、数据字典与本次复现说明；`results/`：实际 Stata 输出和跨软件核对。
