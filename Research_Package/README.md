# 科创金融改革试验区与高技术产业企业进入

本研究使用2018—2023年工商登记资料，以成立日期衡量企业进入。作者为江洁薇娜、李荣耀、王诗颖、李俊言。论文原型讨论科创金融改革试验区与新设高技术产业企业之间的关系，并报告登记行业分类、地区覆盖和政策实施时间对估计的影响。
