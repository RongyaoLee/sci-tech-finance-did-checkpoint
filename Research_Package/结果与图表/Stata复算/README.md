# Stata 真机复算

本目录由随包的 `代码/科创金融_复算.do` 在 Stata/MP 18.0（07 Jun 2023 修订版）中生成。输入为各窗口、各行业识别口径下的 `同期城市面板.csv`。这些面板已由随包 Python 脚本根据月度企业统计、2020 年人口和政策时间表建立。

## 运行

在 Stata 中先进入 `Research_Package` 目录，然后运行：

```stata
do "代码/科创金融_复算.do"
```

在终端或 PowerShell 中，从同一目录运行逐项核对：

```text
python "代码/科创金融_Stata核对.py"
```

do 文件自动处理 2020—2023、2019—2023 两个窗口；若 `结果与图表` 下有首年为 2018、末年为 2023 的完整扩展面板，也处理 2018—2023。每个窗口分别估计主分类与仅四位小类，共七个结果变量。

## 估计口径

Stata 原生命令为 `regress Y treated i.city_code i.year if benchmark_eligible == 1, vce(cluster city_code)`。估计前执行与 Python `--balanced` 对应的整市平衡筛选：每座城市须具备窗口内除政策过渡年外的全部可用年份。`benchmark_eligible` 排除北京及各试点城市的政策过渡年；缺失结果变量由 Stata 回归自动排除。

`hightech_per_10k` 是按 2020 年人口计算的每万人高技术企业新设数；`hightech_share` 是高技术企业新设数占全部新设企业数的比例，系数乘以 100 后为百分点。其余变量包括高技术新设数、其 `ln(1+x)`、制造业和服务业新设数，以及全部企业每万人新设数。

Stata 的双侧 p 值使用城市聚类数减一的 t 分布自由度。现有 Python 实现采用相同的聚类有限样本修正和自由度，因此两边结果应在数值精度内一致。

## 文件

- `Stata_TWFE_原生结果.csv`：Stata 直接输出的系数、城市聚类标准误、双侧 p 值、观测数、城市聚类数、处理城市数和自由度。
- `复算日志.txt`：Stata 直接写出的版本与逐项模型结果，不含本机许可信息和私人路径。
- `Stata与Python逐项核对.csv`：核对脚本逐项比较 Stata 与随包 Python 表。`PASS` 同时要求数值、样本量、聚类数、处理城市数和自由度一致；输入面板晚于 Stata 结果时标记为过期。

核对命令成功退出时，会在终端打印各统计量的最大绝对差。修订输入面板后，请先重新运行 do 文件，再运行核对脚本。
